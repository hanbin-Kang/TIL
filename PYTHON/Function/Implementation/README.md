
# ☕️ Cafe Order System (카페 주문 시스템)

파이썬의 중첩 딕셔너리(Nested Dictionary) 구조와 재귀적 탐색을 활용한 카페 주문 관리 프로그램입니다.

---

## 📌 1. 메모리 구조 도식 (Memory Reference Diagram)

파이썬 내부에서 중첩 딕셔너리가 참조 주소(Reference)를 통해 어떻게 연결되는지 시각화한 구조도입니다.

![Memory Diagram](./memory_digaram.PNG)

* **Primitive vs Reference**: 단일 값(가격)과 하위 옵션 딕셔너리가 각각 메모리 주소를 가지며 계층적으로 연결됨을 표현했습니다.

## 🛠️ 2. 핵심 구현 기능 (Current Progress)

- [x] **0단계 - 메뉴 및 데이터 구조 정의**: 중첩 딕셔너리를 활용한 메뉴판 구성 (26-08-24)

## 🗺️ 3. 향후 개발 로드맵 (Roadmap)

- [ ] **1단계 - 입력 검증 (Exception Handling)**: 예외 처리 및 검증 logic을 통해 잘못된 메뉴/옵션 입력 시 프로그램  다운 방지
- [ ] **2단계 - 주문 목록 기능**: 단일 주문을 넘어 여러 항목을 리스트 형태로 저장
- [ ] **3단계 - 총액 계산 함수**: 주문 목록을 바탕으로 총 결제 금액 자동 계산
- [ ] **4단계 - 주문 수정 / 삭제**: 수량 변경 및 선택 항목 삭제 기능 구현
- [ ] **5단계 - 장바구니 (Cart)**: 바로 결제 방식에서 장바구니 수집 단계로 전환
- [ ] **6단계 - 결제 시스템**: 결제 로직 모듈화 및 시뮬레이션

---

## 🎯 4. 최종 목표 (Final Goal)

- **Database 연동**: 월별 판매량, 메뉴별 인기 순위, 매출 데이터를 다루는 DB 설계
- **Web Kiosk UI**: 실제 매장에서 사용하는 형태의 웹 키오스크 인터페이스 구축
- **AI Agent 연동**: 자연어 입력 기반 대화형 주문 AI 시스템 통합
