# CPU의 구성 요소와 레지스터

CPU는 메모리에 저장된 명령어를 읽고, 해석하고, 실행하는 장치이다.

CPU는 크게 다음과 같은 구성 요소로 이루어진다.

* **ALU(산술논리연산장치)** : 계산을 담당
* **제어장치** : 명령어를 해석하고 제어 신호를 생성
* **레지스터** : CPU 내부에서 명령어와 데이터를 일시적으로 저장

---

## ALU

**ALU(Arithmetic Logic Unit)**는 산술 연산과 논리 연산을 수행하는 장치이다.

계산을 수행하려면 **피연산자**와 **수행할 연산**에 대한 정보가 필요하다.

### ALU의 동작

* 레지스터에서 피연산자를 받아 연산한다.
* 연산 결과를 레지스터에 저장한다.
* 제어장치가 보낸 제어 신호를 받아 어떤 연산을 수행할지 결정한다.
* 연산 결과와 함께 **플래그**를 생성하여 플래그 레지스터에 저장한다.

> CPU가 메모리보다 레지스터에 더 빠르게 접근할 수 있기 때문에, CPU 내부에서 당장 사용할 값은 레지스터에 저장하여 처리한다.

### 플래그

**플래그(Flag)**는 연산 결과나 CPU의 현재 상태를 나타내는 부가 정보이다.

예를 들어 연산 결과가 0인지, 음수인지 등의 정보를 나타낼 수 있다.

---

## 제어장치

**제어장치(Control Unit)**는 명령어를 해석하고, 컴퓨터의 각 부품이 동작하도록 **제어 신호**를 생성하여 보내는 장치이다.

### 제어장치가 받는 정보

* **클럭 신호**

  * 컴퓨터의 여러 부품이 일정한 박자에 맞춰 동작하도록 하는 신호
* **명령어 레지스터의 명령어**

  * 메모리에서 가져온 명령어
  * 제어장치가 명령어를 해석한다.
* **플래그 레지스터의 플래그**

  * 연산 결과나 CPU 상태에 대한 부가 정보
* **제어 버스를 통해 전달되는 제어 신호**

  * CPU 외부의 메모리나 입출력장치 등에서 전달되는 제어 신호

### 제어장치가 내보내는 정보

* **CPU 내부**

  * 레지스터와 ALU 등에 제어 신호를 보낸다.
* **CPU 외부**

  * 제어 버스를 통해 메모리나 입출력장치 등에 제어 신호를 보낸다.

---

# 레지스터

**레지스터(Register)**는 CPU 내부에 있는 작은 저장장치이다.

CPU가 명령어를 실행하는 과정에서 필요한 **명령어, 데이터, 주소, 연산 결과 등의 정보를 일시적으로 저장**한다.

레지스터는 종류에 따라 담당하는 역할이 다르다.

## 프로그램 카운터(PC)

**프로그램 카운터(Program Counter)**는 다음에 메모리에서 가져올 **명령어의 주소**를 저장한다.

```text
프로그램 카운터
      ↓
"다음 명령어가 메모리의 몇 번지에 있는가?"
```

---

## 명령어 레지스터(IR)

**명령어 레지스터(Instruction Register)**는 **메모리에서 방금 가져온 명령어**를 저장한다.

제어장치는 명령어 레지스터에 저장된 명령어를 받아 해석한다.

```text
메모리
  ↓
명령어
  ↓
명령어 레지스터
  ↓
제어장치가 해석
```

---

## 메모리 주소 레지스터(MAR)

**메모리 주소 레지스터(Memory Address Register)**는 CPU가 접근할 **메모리의 주소**를 저장한다.

주소 버스와 관련되어 있다.

```text
MAR
 ↓
메모리 주소
 ↓
주소 버스
```

---

## 메모리 버퍼 레지스터(MBR)

**메모리 버퍼 레지스터(Memory Buffer Register)**는 CPU와 메모리 사이에서 주고받는 **값**을 저장한다.

명령어 또는 데이터를 저장할 수 있으며, 데이터 버스와 관련되어 있다.

```text
메모리 ←→ 데이터 버스 ←→ MBR
```

---

## 플래그 레지스터

**플래그 레지스터(Flag Register)**는 연산 결과나 CPU 상태에 대한 **부가적인 정보인 플래그**를 저장한다.

예를 들어 연산 결과가 0인지, 음수인지 등의 상태를 나타낼 수 있다.

---

## 범용 레지스터

**범용 레지스터(General Purpose Register)**는 다양한 상황에서 자유롭게 사용할 수 있는 레지스터이다.

연산에 필요한 값이나 임시 데이터를 저장하는 등 여러 용도로 사용된다.

---

# 스택 포인터

**스택 포인터(Stack Pointer)**는 스택의 **현재 최상단 위치를 가리키는 레지스터**이다.

스택을 이용하는 과정에서 현재 스택의 위치를 나타내는 데 사용된다.

### 스택 주소 지정 방식

스택과 스택 포인터를 이용하여 메모리에 접근하는 주소 지정 방식이다.

---

# 베이스 레지스터

**베이스 레지스터(Base Register)**는 기준이 되는 주소를 저장하는 레지스터이다.

### 변위 주소 지정 방식

**변위 주소 지정 방식**은 오퍼랜드 필드의 값인 **변위(displacement)**와 특정 레지스터의 값을 더하여 **유효 주소**를 계산하는 방식이다.

```text
유효 주소 = 레지스터 값 + 오퍼랜드(변위)
```

명령어는 다음과 같은 형태로 표현할 수 있다.

```text
연산 코드 | 레지스터 | 오퍼랜드
```

### 상대 주소 지정 방식

특정 레지스터가 **프로그램 카운터(PC)**인 경우이다.

```text
유효 주소 = PC 값 + 오퍼랜드
```

### 베이스 레지스터 주소 지정 방식

특정 레지스터가 **베이스 레지스터**인 경우이다.

```text
유효 주소 = 베이스 레지스터 값 + 오퍼랜드
```

# CPU 동작의 큰 흐름

CPU는 메모리에 저장된 명령어를 가져와 해석하고 실행한다.

```text
메모리
  ↓
명령어 가져오기
  ↓
명령어 레지스터(IR)에 저장
  ↓
제어장치가 명령어 해석
  ↓
필요한 데이터와 제어 신호 준비
  ↓
ALU 등이 명령어 실행
  ↓
결과를 레지스터 등에 저장
```

### 핵심 정리

```text
CPU
├── ALU
│   └── 연산 수행
│
├── 제어장치
│   └── 명령어 해석 + 제어 신호 생성
│
└── 레지스터
    └── 명령어 / 데이터 / 주소 / 결과 등을 임시 저장
```

**핵심은 CPU가 메모리에서 명령어와 데이터를 가져와 레지스터 등을 이용해 처리하고, 제어장치는 전체 동작을 제어한다는 것이다.**
