# 관계형 데이터베이스

관계형 데이터베이스(RDB)는 데이터를 기본적으로 **2차원 표 형태**로 저장하고 관리한다.

- **테이블(Table)** : 데이터를 저장하는 공간
- **행(Row)** : 하나의 데이터(레코드), 가로줄
- **열(Column)** : 데이터의 속성, 세로줄

## 키(Key)

키(Key)는 테이블에서 특정 행을 식별하거나 **테이블 간의 관계를 표현**하기 위해 사용한다.

주요 키에는 다음이 있다.

- 기본키(Primary Key)
- 후보키(Candidate Key)
- 대체키(Alternate Key)
- 외래키(Foreign Key)
- 복합키(Composite Key)

### 후보키 (Candidate Key)

테이블의 각 행을 **유일하게 식별할 수 있는 최소한의 속성**이다.

조건:
1. 각 행을 유일하게 식별할 수 있어야 한다. → **유일성**
2. 행을 식별하는 데 필요한 최소한의 속성으로 구성되어야 한다. → **최소성**
3. NULL 값을 가질 수 없다.

후보키 중 하나를 선택하여 **기본키(Primary Key)**로 지정하고,
기본키로 선택되지 않은 나머지 후보키를 **대체키(Alternate Key)**로 한다.

### 기본키 (Primary Key)

후보키 중에서 **하나를 선택하여 대표 식별자로 지정한 키**이다.

조건:
1. 테이블의 각 행을 유일하게 식별할 수 있어야 한다.
2. 중복된 값을 가질 수 없다.
3. NULL 값을 가질 수 없다.

> 기본키는 후보키 중 하나를 선택한 것이다.

### 대체키 (Alternate Key)

후보키 중에서 **기본키로 선택되지 않은 나머지 후보키**이다.

> 대체키 = 후보키 중 기본키가 아닌 후보키

예를 들어 후보키가 `학번`, `주민번호`이고 `학번`을 기본키로 선택했다면:

- `학번` → 기본키(PK)
- `주민번호` → 대체키(Alternate Key)
- `학번`, `주민번호` → 후보키(Candidate Key)

### 외래키 (Foreign Key)

**다른 테이블의 기본키 또는 후보키를 참조하는 키**이다.

외래키를 사용하면 서로 다른 테이블을 **관계로 연결**할 수 있다.

예를 들어 `DEPT` 테이블의 `DEPTNO`가 기본키이고,
`EMP` 테이블의 `DEPTNO`가 이를 참조한다면:

```text
DEPT
DEPTNO (PK)
   ↑
   │ 참조 (다른 테이블의 특정 키를 기준으로 연결한다.)
   │
EMP
DEPTNO (FK)
