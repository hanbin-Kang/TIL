# Oracle 함수

## 1. DUAL 테이블

**DUAL 테이블**은 실제 데이터를 저장하기 위한 테이블이 아니라, **계산이나 함수의 결과를 확인할 때 사용하는 테이블**이다.

```sql
SELECT SYSDATE
FROM DUAL;
```

---

## 2. 함수의 종류

### 오라클에서 제공하는 함수

* **내장 함수(Built-in Function)**
* **사용자 정의 함수(User-Defined Function)**

### 내장 함수의 종류

#### 단일행 함수

* 데이터가 한 행씩 입력됨
* 입력된 한 행마다 하나의 결과를 반환

#### 다중행 함수

* 여러 행의 데이터가 입력됨
* 여러 행을 하나의 결과로 반환

# 3. 문자열 함수

문자 데이터를 가공할 때 사용하는 함수

## 대소문자 변환

### `UPPER(str)`

문자 데이터를 모두 **대문자**로 변환

```sql
SELECT UPPER('hello')
FROM DUAL;
```

### `LOWER(str)`

문자 데이터를 모두 **소문자**로 변환

```sql
SELECT LOWER('HELLO')
FROM DUAL;
```

### `INITCAP(str)`

각 단어의 첫 글자는 대문자로, 나머지는 소문자로 변환

```sql
SELECT INITCAP('hello oracle')
FROM DUAL;
```

> `UPPER`, `LOWER`, `INITCAP`은 `SELECT`, `WHERE` 등에서 자주 사용된다.

---

## 문자열 길이 구하기

### `LENGTH(str)`

문자열의 길이를 반환

```sql
SELECT LENGTH('ORACLE')
FROM DUAL;
```

### `LENGTHB(str)`

문자열의 **바이트 수**를 반환

> `LENGTH`는 문자의 개수, `LENGTHB`는 바이트 수를 반환한다.

---

## 문자열 일부 추출

### `SUBSTR(str, 시작 위치, 추출 길이)`

시작 위치부터 지정한 길이만큼 문자열을 추출한다.

```sql
SELECT SUBSTR('ORACLE', 2, 3)
FROM DUAL;
```

결과:

```text
RAC
```

시작 위치가 음수이면 **문자열의 뒤에서부터** 위치를 계산한다.

### `SUBSTR(str, 시작 위치)`

시작 위치부터 문자열의 끝까지 추출한다.

```sql
SELECT SUBSTR('ORACLE', 3)
FROM DUAL;
```

결과:

```text
ACLE
```

---

## 특정 문자의 위치 찾기

### `INSTR(문자열, 문자)`

문자열에서 특정 문자가 **처음 등장하는 위치**를 반환한다.

### `INSTR(문자열, 문자, 시작 위치)`

지정한 시작 위치부터 특정 문자의 위치를 찾는다.

### `INSTR(문자열, 문자, 시작 위치, N)`

지정한 시작 위치부터 특정 문자가 **N번째로 등장하는 위치**를 반환한다.

```sql
SELECT INSTR('HELLO ORACLE', 'O')
FROM DUAL;
```

---

## 특정 문자 변경

### `REPLACE(문자열, 찾는 문자, 대체할 문자)`

문자열에서 특정 문자를 다른 문자로 변경한다.

```sql
SELECT REPLACE('010-1234-5678', '-', '')
FROM DUAL;
```

결과:

```text
01012345678
```

> 대체할 문자를 `''`로 지정하면 해당 문자를 삭제할 수 있다.

---

## 문자열의 빈 공간 채우기

### `LPAD(문자열, 전체 길이, 채울 문자)`

문자열의 **왼쪽** 빈 공간을 지정한 문자로 채운다.

### `RPAD(문자열, 전체 길이, 채울 문자)`

문자열의 **오른쪽** 빈 공간을 지정한 문자로 채운다.

```sql
SELECT LPAD('1234', 8, '*')
FROM DUAL;
```

결과:

```text
****1234
```

개인정보를 `*` 등으로 마스킹할 때 사용할 수 있다.

---

## 문자열 연결

### `CONCAT(문자열1, 문자열2)`

두 문자열을 연결한다.

```sql
SELECT CONCAT('Hello', 'Oracle')
FROM DUAL;
```

`||` 연산자도 문자열을 연결할 때 사용할 수 있다.

```sql
SELECT 'Hello' || 'Oracle'
FROM DUAL;
```

---

## 문자열 삭제

### `TRIM`

문자열의 앞, 뒤 또는 양쪽의 특정 문자를 제거한다.

```sql
TRIM([삭제 옵션] [삭제할 문자] FROM 원본 문자열)
```

삭제 옵션:

* `LEADING` : 앞
* `TRAILING` : 뒤
* `BOTH` : 양쪽

삭제할 문자를 지정하지 않으면 공백을 제거한다.

### `LTRIM`

문자열의 **왼쪽**에서 특정 문자를 제거한다.

```sql
LTRIM(원본 문자열, 삭제할 문자)
```

삭제할 문자를 지정하지 않으면 공백을 제거한다.

### `RTRIM`

문자열의 **오른쪽**에서 특정 문자를 제거한다.

```sql
RTRIM(원본 문자열, 삭제할 문자)
```

삭제할 문자를 지정하지 않으면 공백을 제거한다.

# 4. 숫자 함수

숫자 데이터를 연산하거나 값을 조정할 때 사용하는 함수

## 반올림

### `ROUND(숫자, 반올림 위치)`

지정한 위치에서 반올림한다.

```sql
ROUND(1265.1234, 2)
```

`반올림 위치`를 생략하면 **소수점 첫째 자리에서 반올림**한다.

음수를 지정하면 정수 부분의 자리에서 반올림한다.

```sql
ROUND(1265.1234, -2)
-- 1300
```

---

## 버림

### `TRUNC(숫자, 버림 위치)`

지정한 위치에서 숫자를 버린다.

```sql
TRUNC(1265.1234, 2)
-- 1265.12
```

`버림 위치`를 생략하면 **소수점 이하를 버린다.**

```sql
TRUNC(1265.1234)
-- 1265
```

음수를 지정하면 정수 부분의 자리에서 버린다.

---

## 올림과 내림

### `CEIL(숫자)`

입력된 숫자보다 **크거나 같은 가장 가까운 정수**를 반환한다.

```sql
CEIL(3.14)
-- 4
```

### `FLOOR(숫자)`

입력된 숫자보다 **작거나 같은 가장 가까운 정수**를 반환한다.

```sql
FLOOR(3.14)
-- 3
```

---

## 나머지 구하기

### `MOD(나눗셈될 숫자, 나눌 숫자)`

나눗셈의 나머지를 반환한다.

```sql
MOD(10, 3)
-- 1
```

# 5. 날짜 함수

날짜 데이터를 다룰 때 사용하는 함수

## 날짜 데이터의 기본 연산

### 날짜 + 숫자

날짜에서 숫자만큼 **일수가 증가**한다.

```text
날짜 + 1 → 하루 뒤
날짜 + 7 → 7일 뒤
```

### 날짜 - 숫자

날짜에서 숫자만큼 **일수가 감소**한다.

```text
날짜 - 1 → 하루 전
날짜 - 7 → 7일 전
```

### 날짜 - 날짜

두 날짜 사이의 **일수 차이**를 반환한다.

```text
날짜1 - 날짜2 → 두 날짜 사이의 일수
```

> 날짜 데이터끼리는 뺄셈이 가능하지만, 날짜 + 날짜 연산은 사용할 수 없다.

---

## 현재 날짜와 시간

### `SYSDATE`

데이터베이스 서버가 실행되는 **OS의 현재 날짜와 시간**을 반환한다.

```sql
SELECT SYSDATE
FROM DUAL;
```

---

## 개월 수를 더한 날짜

### `ADD_MONTHS(날짜, 개월 수)`

지정한 날짜에서 입력한 개월 수만큼 지난 날짜를 반환한다.

```sql
SELECT ADD_MONTHS(SYSDATE, 3)
FROM DUAL;
```

---

## 두 날짜의 개월 수 차이

### `MONTHS_BETWEEN(날짜1, 날짜2)`

두 날짜 사이의 개월 수 차이를 반환한다.

```sql
SELECT MONTHS_BETWEEN(
    TO_DATE('2026-12-31', 'YYYY-MM-DD'),
    TO_DATE('2026-01-01', 'YYYY-MM-DD')
)
FROM DUAL;
```

---

## 특정 요일과 달의 마지막 날짜

### `NEXT_DAY(날짜, 요일)`

지정한 날짜 이후에 돌아오는 특정 요일의 날짜를 반환한다.

### `LAST_DAY(날짜)`

해당 날짜가 속한 달의 **마지막 날짜**를 반환한다.

```sql
SELECT LAST_DAY(SYSDATE)
FROM DUAL;
```

# 6. 형 변환 함수

자료형을 다른 자료형으로 변환하는 함수

형 변환에는:

* **자동 형 변환**
* **명시적 형 변환**

이 있다.

함수를 사용하여 직접 형 변환을 지정하는 것을 **명시적 형 변환**이라고 한다.

### 주요 형 변환 함수

| 함수          | 변환            |
| ----------- | ------------- |
| `TO_CHAR`   | 숫자 또는 날짜 → 문자 |
| `TO_NUMBER` | 문자 → 숫자       |
| `TO_DATE`   | 문자 → 날짜       |

---

## 날짜 데이터를 문자로 변환

### `TO_CHAR(날짜, 출력 형식)`

날짜 데이터를 원하는 형식의 문자열로 변환한다.

```sql
SELECT TO_CHAR(SYSDATE, 'YYYY-MM-DD')
FROM DUAL;
```

### 시간 형식

| 형식           | 의미      |
| ------------ | ------- |
| `HH24`       | 24시간 형식 |
| `HH`, `HH12` | 12시간 형식 |
| `MI`         | 분       |
| `SS`         | 초       |
| `AM`, `PM`   | 오전, 오후  |
| `A.M`, `P.M` | 오전, 오후  |

---

## 문자 데이터를 숫자로 변환

### `TO_NUMBER(문자열, 숫자 형식)`

문자 데이터를 숫자 데이터로 변환한다.

```sql
SELECT TO_NUMBER('1,000', '9,999')
FROM DUAL;
```

---

## 문자 데이터를 날짜로 변환

### `TO_DATE(문자열, 날짜 형식)`

문자 데이터를 날짜 데이터로 변환한다.

```sql
SELECT TO_DATE('2026-08-31', 'YYYY-MM-DD')
FROM DUAL;
```

# 7. NULL 처리 함수

## `NVL`

NULL인 데이터를 다른 값으로 변환한다.

```sql
NVL(NULL인지 검사할 데이터, NULL일 경우 반환할 값)
```

예:

```sql
SELECT NVL(COMM, 0)
FROM EMP;
```

`COMM`이 `NULL`이면 `0`을 반환한다.

---

## `NVL2`

NULL인지 여부에 따라 서로 다른 값을 반환한다.

```sql
NVL2(
    검사할 데이터,
    NULL이 아닐 경우 반환할 값,
    NULL일 경우 반환할 값
)
```

예:

```sql
SELECT NVL2(COMM, '수당 있음', '수당 없음')
FROM EMP;
```

# 8. DECODE와 CASE

조건에 따라 서로 다른 값을 반환할 때 사용한다.

## `DECODE`

특정 값과 조건을 비교하여 결과를 반환한다.

```sql
DECODE(
    검사 대상,
    조건1, 결과1,
    조건2, 결과2,
    ...,
    기본 결과
)
```

조건과 일치하는 값이 없고 기본 결과도 지정하지 않으면 `NULL`을 반환한다.

예:

```sql
SELECT DECODE(
    JOB,
    'MANAGER', '관리자',
    'CLERK', '사원',
    '기타'
)
FROM EMP;
```

---

## `CASE`

조건에 따라 서로 다른 결과를 반환한다.

### 단순 CASE

```sql
CASE 검사 대상
    WHEN 조건1 THEN 결과1
    WHEN 조건2 THEN 결과2
    ELSE 기본 결과
END
```

### 검색 CASE

조건식을 직접 작성할 수도 있다.

```sql
CASE
    WHEN 조건1 THEN 결과1
    WHEN 조건2 THEN 결과2
    ELSE 기본 결과
END
```

`CASE`는 `DECODE`보다 다양한 조건식을 표현할 수 있어 실무에서 자주 사용된다.
